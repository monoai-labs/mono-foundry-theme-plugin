# Changelog

All notable changes to the monofoundry LSP plugin are documented here.

## v0.3.1 — 2026-07-08

- Removed the underline from the monokai theme logo for consistency with other themes.
- Bug fixes and internal improvements.

## v0.3.0 — 2026-07-04

- Expanded the theme pack from 18 to 65 themes; 47 new dark and light themes are available in the theme picker.
- Broadened colour coverage so more interface elements adopt the active theme's palette instead of falling back to defaults.
- Fixed markdown blockquote styling that was not applying theme colours.
- Bug fixes and internal improvements.

## v0.2.3 — 2026-07-03

- Actually resolved a packaging issue that caused the plugin to fail to load on install.

## v0.2.2 — 2026-07-03

- Resolved a packaging issue that caused the plugin to fail to load on install.

## v0.2.1 — 2026-07-03

- Bug fixes and internal improvements.

## v0.2.0 — 2026-07-03

- Initial release: 18 colour themes (dark and light) available in the theme picker.
- Themes are removed automatically when the plugin is disabled or uninstalled.
- Requires monofoundry 0.19.0 or later.
- Bug fixes and internal improvements.
