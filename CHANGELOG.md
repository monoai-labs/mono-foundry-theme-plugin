# Changelog

All notable changes to the monofoundry LSP plugin are documented here.

## v0.2.1 — 2026-07-03

- Bug fixes and internal improvements.

## v0.2.0 — 2026-07-03

- Initial release: 18 colour themes (dark and light) available in the theme picker.
- Themes are removed automatically when the plugin is disabled or uninstalled.
- Requires monofoundry 0.19.0 or later.
- Bug fixes and internal improvements.
